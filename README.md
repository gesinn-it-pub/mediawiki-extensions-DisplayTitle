DisplayTitle
============

[![CI](https://github.com/gesinn-it-pub/mediawiki-extensions-DisplayTitle/actions/workflows/ci.yml/badge.svg)](https://github.com/gesinn-it-pub/mediawiki-extensions-DisplayTitle/actions/workflows/ci.yml)
[![codecov](https://codecov.io/gh/gesinn-it-pub/mediawiki-extensions-DisplayTitle/branch/main/graph/badge.svg)](https://app.codecov.io/gh/gesinn-it-pub/mediawiki-extensions-DisplayTitle)

Uses the `displaytitle` page property in link text, subtitles, and talk page
titles, and provides a parser function to query it.

See [mediawiki.org/wiki/Extension:DisplayTitle](https://www.mediawiki.org/wiki/Extension:DisplayTitle)
for full documentation.
